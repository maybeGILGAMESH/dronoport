# Три варианта сети дронопортов: комплект сдачи

Откройте `reports/report.pdf`: LaTeX-статья на 64 страницах с 51 рисунком (26 аналитических рисунков и 25 карт), таблицами методов, расшифровками формул и матрицей требований. HTML-версия: `reports/latex/report.html`. Последовательная автономная сборка описана в `LATEX_README.md`. Графики Cinematic Atlas имеют белый фон; исходные SVG, PDF, PNG 300 dpi и численные таблицы находятся в `reports/article/figures` и `reports/article/evidence`.

| --- | ---: | ---: | ---: |
| A. Базовая временная модель | 491 700 | 2 769 468 699 | 11 / 5 |
| B. CP-SAT и сравнение GA с отжигом | 501 600 | 2 770 424 709 | 11 / 5 |
| C. Порт и рейсы в каждой области | 485 100 | 2 981 865 879 | 13 / 5 |

Вариант И включает Московскую, Смоленскую и Тверскую области. Пять букв ЖЗИКЛ относятся к названиям поселений. Региональный вариант C требует порта и фактических рейсов в каждой области к третьему году. A и B имеют одинаковые инвестиции и базы; C имеет более строгое условие и два дополнительных порта. Разница результатов не является рейтингом алгоритмов на одной задаче.

В парной серии из десяти seed GA и отжиг с общим CP-декодером дали одинаковые 498 300 поездок. Итог B, 501 600, получен после дополнительного распределения пассажиров. Этот прирост не приписывается GA. Результаты являются проверенными допустимыми планами; глобальная оптимальность не доказана.

## Что сохранено

- `variants/A_baseline`, `variants/B_cp_ga`, `variants/C_regional`: исходные ZIP без изменений, их прежние контрольные суммы и проверки. Внутри каждого находятся соответствующие старые отчёты, код и результаты.
- `variants/supplement_legacy`: ранняя коридорная модель как дополнительный материал, вне трёх основных вариантов.
- `runs/20261106_154352_regional`: общая копия сохранённых вычислений. A находится в `base`, B в `cp_ga/final_best`, C в `regional/final_best`. Исторический отчёт в `report/report.pdf` внутри запуска не заменён новой статьёй.
- `src`, `scripts`, `config`, `tests`: код проекта и новой сборки статьи. Исторические снимки исходников находятся в исходных комплектах и `source_snapshot`.
- `data/processed`, `data/processed_v2`, исходные XLSX и PDF задания: данные, реестры и первичные предоставленные документы. Большие OSM/PBF и XML ГАР, окружение `.venv`, кэши исключены. Источники перечислены в `DOWNLOADS.md`, `data/processed_v2/gar_sources.json` и журналах происхождения.
- `reports/executive_summary.md`: управленческая записка; `reports/article/article.md`: редактируемый текст; `reports/latex/validation.json`: проверка нового отчёта; `reports/article/tests.xml`: результаты 55 тестов.
- `docs/methods`: использованные навыки humanizer и Scientific Visualization, их происхождение и лицензии; сведения об Atlas из исследования tensor.

## Автономные карты

Откройте `reports/article/maps/network.html` (A), `network_cp_ga.html` (B) или `network_regional.html` (C). Переносите каталог `maps` вместе с `assets`. Внешние тайлы и VPN не нужны. Статья и все три карты проверены в Chromium и Firefox при отключённой сети.

## Воспроизведение

Из корня распакованного комплекта, Python 3.12+:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-latex.txt
.venv/bin/python scripts/build_latex_report.py
.venv/bin/python scripts/check_latex_report.py
.venv/bin/python -m pytest -q
```

Для PDF используются системные шрифты DejaVu (`fonts-dejavu-core` в Debian/Ubuntu). Пересборка статьи читает готовые результаты, не запускает оптимизацию. Дата/метаданные PDF могут отличаться при повторном рендеринге; численные таблицы должны совпадать. Команды численных экспериментов и лимиты находятся в `README.md`, `MODEL_V2.md`, `MODEL_CP_GA.md` и исходных комплектах. Запускать новые расчёты следует в отдельных каталогах, сохраняя опубликованные результаты.

Для дополнительной браузерной проверки нужны Chrome и Playwright Firefox:

```bash
.venv/bin/python -m playwright install firefox
.venv/bin/python scripts/check_article.py --output reports/article --browsers
```

Скрипт использует Chrome по пути `/usr/bin/google-chrome`. На другой платформе путь необходимо изменить. Обычное чтение отчёта и карт не требует Python или Playwright.

## Ограничения, которые сохранены в статье

Географическое сопоставление полного официального реестра не завершено. Полная MIP на 30 пунктах остановлена по памяти; полного сравнения совместного и последовательного MIP на этом размере нет. Эти три пункта отмечены как частичные. Население с пропусками не заполнялось. Спрос, цены и типичные сутки являются учебными допущениями. Региональное обслуживание гарантируется для нормального режима; отказ единственного порта области нарушает его. Стресс-тесты разных версий имеют разные бюджеты перепланирования и не используются для прямого рейтинга устойчивости.

`delivery_manifest.json` содержит SHA-256 каждого файла комплекта. Внешний файл `.sha256` проверяет сам архив, `.verification.json` фиксирует проверку содержимого и переносимой пересборки.

Проверка самого объединённого архива и переносимой пересборки:

```bash
.venv/bin/python scripts/verify_three_variants.py /путь/к/droneport_three_variants_research_20261106.zip --rebuild
```

Проверка использует временную распакованную копию и установленное окружение, сверяет каждый SHA-256, затем повторно строит статью и сравнивает текст и все численные таблицы. Исходные оптимизаторы не запускаются.

Аудит всех семи запусков и дополнительные выводы: `RESEARCH_AUDIT_README.md`. Исходные каталоги всех запусков включены в новый комплект.
