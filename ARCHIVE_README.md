# Переносимый комплект

Дополнение `*_cp_ga` содержит отдельные эксперименты CP-SAT и 10 парных запусков
генетического алгоритма/отжига. В начале PDF — новые результаты, далее — сохранённое
базовое исследование. `cp_ga/search_best` — результат самой поисковой серии;
`cp_ga/final_best` — итог после отдельного распределения пассажиров при сценарной проверке.
Не приписывать последнее улучшение GA. Карта итогового плана — `reports/maps/network_cp_ga.html`.
Математика и протокол дополнения — `MODEL_CP_GA.md`, команды — README.

В расширенном комплекте v2 карта автономна, а `results_v2/current_run.txt` указывает
включённый каталог `runs/<run_id>_v2`. Исходный код численного запуска сохранён в `source_snapshot`;
последующие уточнения восстановления сценариев зафиксированы в `recourse_revision.json`.
Проверки всех публикуемых планов — `delivery_validation.json`, контрольные суммы —
`run_manifest.json` и `delivery_manifest.json`.

Полная серия v2 включает длительные MIP-решения. Для технического прогона:
`.venv/bin/python scripts/run_project.py --experiments quick --solver-seconds 30`.
Для чтения отчёта, карты и CSV установка Python не нужна. Папку `maps/assets` нужно переносить вместе с HTML.

Сырые XML ГАР в архив не включаются; включены извлечённый официальный перечень, журнал
сопоставлений и ссылки/хэши исходных XML. Восстановление выбранных XML без скачивания полного
общероссийского ZIP: `.venv/bin/python scripts/audit_gar_v2.py`.

Архив содержит код, конфигурации, тесты, документацию, исходный PDF, 11 XLSX Росстата,
обработанные данные, текущий расчёт, подробный журнал запуска, HTML/PDF и карту.
`.venv`, кэши, старые запуски и PBF на 884 МБ не включаются.

Для чтения результатов ничего скачивать не требуется. Для пересчёта на сохранённой выборке
достаточно установить зависимости и выполнить `.venv/bin/python scripts/run_project.py`.

Для повторного извлечения геоданных нужен `central-fed-district-261103.osm.pbf` в корне:

- [Страница Geofabrik](https://download.geofabrik.de/russia/central-fed-district.html).
- [Датированный снимок](https://download.geofabrik.de/russia/central-fed-district-261103.osm.pbf).
- SHA-256: `fee73607808b1a0c40afa26c6fa8a9de133fd93940d54f17487389cc177c103d`.

Если исторический файл недоступен, актуальный `latest` — другой вход: нужно обновить
`local_inputs.yaml`, выполнить аудит и подготовку данных. Это уже не повтор исходного эксперимента.

Карта использует OpenStreetMap © contributors. Условия геоданных сохраняются у первоисточника;
ссылки и хэши ГАР — в `data/processed_v2/gar_sources.json`, происхождение остальных входов —
в `input_inventory.csv` и документации комплекта. Цены и спрос — учебные допущения.
